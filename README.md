# InviteMe — Wedding Invitation

A simple, elegant web-based wedding invitation generator.

## Features

- Customize bride & groom names, date, time, venue, address, host, and personal message
- Multiple theme options (cream, green, rose)
- Live preview of the invitation card
- Download / print the invitation
- Share via WhatsApp with a pre-filled message

## How to use

1. Open `index.html` in any modern web browser
2. Fill in the form fields on the left
3. Choose a template/theme
4. Preview the invitation on the right
5. Use the **Download** button to print or save as PDF
6. Use the **Share** button to open WhatsApp with a ready-to-send invitation message

No build step or server required — just open the HTML file.
